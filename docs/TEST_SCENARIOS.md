### 执行发布

| # | 场景 | 操作 | 预期 |
|---|------|------|------|
| E1 | 正常视频发布 | 1 条视频任务，账号已登录 | 发布成功，飞书回写「已发布」+ 时间 |
| E2 | 正常图文发布 | 1 条图文任务（3 张图） | 发布成功，飞书回写 |
| E3 | 视频发布 + 音乐融合 | 1 条视频任务，音乐名称列有值 | CDP 下载音乐 → AVFoundation 合并视频 → 上传合并后视频，发布成功 |
| E4 | 图文发布（无音乐融合） | 1 条图文任务 | 图文作品不支持音乐融合，正常发布 |
| E5 | 定时发布 | 设置未来时间 | 抖音显示定时发布，飞书回写「已发布」 |
| E6 | 批量发布 | 5 条混合任务（视频/图文/有无音乐） | 逐条执行，进度条正确，统计正确 |
| E7 | 失败重试 | 故意让 1 条失败，再次执行 | 失败任务被重新拉取并重试 |
| E8 | 暂停/继续 | 执行中点击暂停 → 继续 | 当前任务完成后暂停，继续后恢复 |
| E9 | 停止执行 | 执行中点击停止 | 当前任务标记失败，剩余保持原状 |
| E10 | Cookie 过期（执行中） | 模拟 Cookie 过期 | 检测到登录页跳转，当前任务+该账号所有剩余任务标记失败，继续下一个账号 |
| E10b | 验证码触发 | 发布过程中触发验证码 | 任务暂停，三重提醒（Dock弹跳+通知+声音），用户手动处理后自动继续 |
| E10c | 音乐下载时登录过期 | 音乐融合流程中 Cookie 过期 | 检测到登录页，跳过该账号所有剩余任务 |
| E11 | 素材类型混合 | 表格中一行同时有图片和视频 | 标记失败，原因：素材类型混合 |
| E12 | 无素材 | 表格中附件列为空 | 标记失败，原因：缺少作品素材 |
| E13 | 定时过期 | 定时发布时间已过 | 标记失败，原因：定时发布时间已过期 |
| E14 | 系统通知 | 执行完成 | macOS 系统通知弹出，内容正确 |
| E15 | 视频封面设置 | 发布视频 | 点击「选择封面」→ 弹窗加载 → 点击「完成」→ 封面设置成功 |
| E16 | 话题标签处理（逗号分隔） | 话题列填 `美食,探店,深圳` | 逐个输入 `#美食` `#探店` `#深圳`，每个通过话题选择器选中 |
| E16b | 话题标签处理（换行+#分隔） | 话题列填 `#女装`（换行）`#男装` | 正确解析为两个标签，逐个输入并选中 |
| E17 | 发布状态回写「发布中」 | 开始执行某任务 | 飞书表格该行立即变为「发布中」 |
| E18 | 多账号串行切换 | 2 个账号各有任务 | 第一个账号完成后切换第二个，Cookie 隔离 |

### 边界场景

| # | 场景 | 预期 |
|---|------|------|
| B1 | 飞书超过 500 条记录 | 自动分页拉取所有记录 |
| B2 | 网络中断（执行中） | 当前任务标记失败，暂停队列，提示用户 |
| B3 | 执行中关闭 App | 弹出确认对话框 |
| B4 | 大视频上传（1GB+） | 在超时范围内完成上传或超时标记失败 |
| B5 | 话题标签含逗号、换行、空格、# 前缀 | 正确解析为独立标签，去除 `#` 前缀和空格，支持混合格式 |
| B6 | 文案含换行符 | 保留换行传递到抖音 |
| B7 | App 崩溃后重启 | 「发布中」孤儿任务被重新纳入执行 |
| B8 | 账号无创作者中心权限 | 标记失败，原因明确 |
| B9 | Chrome 进程崩溃 | 自动重启 Chrome，日志记录 |
| B10 | 磁盘空间不足 | 标记失败，原因：磁盘空间不足 |
| B11 | 音乐下载成功 | CDP 网络拦截获取音频 URL，下载成功，合并视频后上传 |
| B12 | 音乐搜索无结果 | 日志警告，跳过音乐融合，上传原始视频（不阻断） |
| B13 | 音乐名称为空 | 不执行音乐下载，直接上传原始视频 |
| B14 | 音乐下载超时 | 日志警告，跳过音乐融合，上传原始视频 |
| B15 | 视频+音乐合并失败 | AVFoundation 合并出错，日志警告，上传原始视频 |
| B16 | 抖音号不匹配 | 执行概览标记未匹配，提示重新登录 |
| B17 | 文案+话题超过 1000 字 | 日志警告，仍尝试发布 |
| B18 | 网络不可用（执行前） | 禁止执行，提示检查网络 |
| B19 | 不支持的文件格式（.gif） | 标记失败，原因：不支持的文件格式 |
| B20 | 多个视频附件 | 标记失败，原因：不支持多视频 |
| B21 | 飞书回写失败 | 日志警告，不影响后续任务 |
| B22 | 飞书 API 限流（429） | 自动等待后重试 |
| B23 | PAT 过期（执行中） | 提示用户更新 PAT，暂停执行 |
| B24 | 单账号连续发布超过 10 条 | 达到上限后自动等待 5 分钟 |
